# James XI Clone

## Project Overview

The **James XI Clone** is a replica of the original website [James XI](https://www.jamesxi.com/), created for educational purposes. This project aims to help myself to explore and understand the latest design trends in modern web development.

## Purpose

- To analyze and replicate contemporary web design patterns.
- To enhance the knowledge of how modern websites design patterns.
- To understand how modern websites structure and present their content.

## Credits

This project is a clone of the original **James XI** website. All rights and original content belong to [James XI](https://www.jamesxi.com/). This clone is strictly for **educational purposes only** and is not intended for commercial use.

## Technologies Used

- **Front-end:** HTML, CSS, JavaScript

## Installation & Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/james-xi-clone.git
   ```
2. Navigate to the project folder:
   ```bash
   cd james-xi-clone
   ```
3. Open `index.html` in a web browser to view the clone.
